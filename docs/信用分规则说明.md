# 信用分机制说明

> 适用于：校园二手书小程序、H5 学生端、管理后台
> 最后更新：2026-10

## 一、这是什么

信用分是系统给每个学生账号打的"靠谱程度"分，取值范围 **0 ~ 100**，新用户注册后从 **80 分**起步。

它解决的问题很具体：二手书交易是陌生人之间的线下交付，买家最怕遇到"图是官图、货是盗版"或者约好了不来。信用分把历史行为沉淀成一个数字，让买家在下单前能快速判断对方靠不靠谱。

分数不是装饰品，直接挂钩三项实际权益：

| 分数区间 | 等级 | 能做什么 |
|---|---|---|
| 95 ~ 100 | 黄金信用 | 发布免审核、立即上架；首页优先展示；黄金标识 |
| 85 ~ 94 | 白银信用 | 正常发布（需审核）；搜索略微靠前；白银标识 |
| 70 ~ 84 | 青铜信用 | 正常发布（需审核） |
| 60 ~ 69 | 待提升 | 正常发布（需审核） |
| 0 ~ 59 | 受限 | **禁止发布新书**，只能浏览和购买 |

## 二、怎么涨分

| 行为 | 分值 | 说明 |
|---|---|---|
| 完成一笔交易（作为卖家） | +2 | 买家确认收货、订单走完流程 |
| 完成一笔交易（作为买家） | +1 | 如约取书，不无故失联 |
| 收到一条好评 | +1 | 评价 4 星及以上才算 |
| 资料填写完整 | +2 | 头像、专业、签名都填上，一次性奖励 |

加分在订单完成、评价提交时由后端自动结算，不需要手动操作。

## 三、怎么扣分

管理员核实举报成立后，**按举报原因分级扣分**——标错价和骗钱不该是同一个代价：

| 举报原因 | 扣分 | 典型场景 |
|---|---|---|
| 涉嫌诈骗 | **-20** | 收款后不发货、货不对板 |
| 内容违规 | -15 | 盗版、涉黄涉政 |
| 疑似虚假信息 | -10 | 冒用书号、图文严重不符 |
| 交易纠纷 | -8 | 约好不来、临时加价 |
| 书况与描述不符 | -5 | 品相、笔记情况和描述差太多 |
| 价格异常 | -3 | 明显偏离市场价 |
| 其他 | -5 | 兜底 |

除此之外：

- **订单超时**：卖家 24 小时内不确认预约，系统自动取消订单并释放书籍，双方各收到一条通知（不扣分，但会影响成交率）
- **手动调整**：管理员可在后台按需调整任意用户的信用分，必须填写原因，系统会推送站内通知告知本人

## 四、分数怎么影响发布

发布流程会因为信用分走不同分支：

```
用户点击"发布"
      │
      ├── 信用 < 60  →  直接拒绝："信用分低于 60 分，暂时无法发布新书"
      │
      ├── 60 ≤ 信用 < 90  →  提交成功，状态"待审核"，管理员审核后上架
      │
      └── 信用 ≥ 90  →  提交成功，立即上架，并标记 priority=1
                        （首页排序靠前、审核列表置顶、卡片左侧显示金色细线）
```

## 五、界面上的呈现

**小程序「我的」页**顶部有一张信用卡：

- 分数字体颜色随等级变化（黄金 #c8901f / 白银 #7c8da3 / 青铜 #b0805a / 待提升 #c0563f）
- 卡片背景随等级渐变（黄金是香槟金 + 顶部细金线）
- 三个特权筹码：免审核上架 / 首页优先 / 专属标识，已解锁的高亮，未解锁的置灰
- 点击卡片展开内联规则，或点"查看如何提分"进入完整说明页

**信用说明页**（`pages/credit`）包含：当前分数、等级进度条、等级特权表、加分项、扣分项。

## 七、已知限制

1. **加分规则目前是硬编码常量**，改动需要重新编译后端；生产环境建议做成可配置表
2. **没有分数变动流水**，用户只能看到当前分数，看不到"哪天因为什么扣了分"。通知里有记录，但没有独立的账单页
3. 信用分只在**举报成立**时扣，日常的"取消订单"目前不扣分（原设计有，实现时去掉了，避免误伤）
