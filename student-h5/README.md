# 学生端 H5

校园二手书系统的移动端学生界面，选题报告里的小程序端在这里先落成一版网页，
方便答辩时直接在浏览器演示，手机扫码访问同一套页面。

## 启动

```powershell
cd student-h5
npm install
npm run dev      # http://127.0.0.1:5174
npm run build    # 产物在 dist/
```

依赖后端：
```powershell
& 'E:\dev\_scripts\backend-start.ps1'   # :8080
& 'E:\dev\_scripts\algo-start.ps1'      # :5001（定价与推荐）
```

## 页面

| 路由 | 说明 |
|---|---|
| /login | 演示登录，三个账号分别模拟买家 / 卖家 / 新用户 |
| / | 首页：广告轮播、分类入口、个性化推荐、最新上架 |
| /search | 检索：关键词 + 排序 + 品相/价格筛选，登录后显示匹配度 |
| /book/:id | 详情：书况四维、价格对比、卖家信息、相似书籍、预约自提 |
| /publish | 发布：书况表单 + 智能定价（建议价 / 区间 / 提示，一键采纳） |
| /orders | 订单：我买到的 / 我卖出的，确认、完成、取消、评价 |
| /me | 我的：资料、信用分、我的发布与收藏 |

## 设计说明

- **暖米色底 + 深绿主色**，接近实体书店的气质，和后台的深色大屏区分开。
- **书况四维**（品相 / 新旧 / 笔记 / 热度）用五格条可视化，
  对应选题报告里「让二手书的质量可被描述和比较」。
- 桌面上自动收窄成 430px 居中，手机上占满整屏，一套代码两种场景。

## 与小程序端的关系

小程序端（`miniprogram/`）是原生 WXML/WXSS 实现，页面结构和这里一一对应，
两边共用同一套后端接口。H5 用于快速演示和真机以外的场景，小程序端用于正式交付。
