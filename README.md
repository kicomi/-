## 一、项目简介

### 1.1 背景

每学期开学和期末，校园里存在大量教材流转需求：低年级同学要买教材，高年级同学手里有闲置的书。现有渠道有三个明显问题：

- **群聊刷屏**：二手群信息秒沉，想找一本《高等数学》要翻几百条消息
- **定价靠猜**：卖家不知道自己的书值多少钱，标高了没人问，标低了吃亏
- **信任缺失**：陌生人线下交易，买家怕货不对板，卖家怕遇到放鸽子的

### 1.2 目标

做一个面向校园的二手教材流转平台，解决三件事：

| 问题 | 本系统的做法 |
|---|---|
| 找书难 | 关键词 + 拼音首字母搜索、按专业/课程分类、协同过滤推荐 |
| 定价难 | 基于书况、原价、市场热度的回归模型给出参考价与区间 |
| 信任难 | 信用分体系、实名学号、评价、举报与管理员介入 |

### 1.3 成果

- 四个客户端：微信小程序、H5 学生端、管理后台、算法服务
- 87 个后端接口，18 张数据表，14 个小程序页面
- 定价模型 MAE 3.94 元（占原价 6.83%），推荐融合 Recall@10 0.4322

## 四、小程序使用说明（逐页）

小程序共 **14 个页面**，底部 5 个 tab：首页 / 找书 / 发布 / 订单 / 我的。

### 4.1 首页 `pages/home`

打开小程序的第一屏，承担"让用户 3 秒找到想看的书"的任务。

| 区域 | 内容 | 交互 |
|---|---|---|
| 顶部 | 搜索框、在售数量 | 点击跳搜索页 |
| 轮播 | 运营配置的广告位 | 点击跳转对应分类/活动 |
| 分类 | 8 个学科图标（计算机、数学、外语…） | 点击按分类筛选 |
| 猜你想找 | 个性化推荐流（基于浏览/收藏/专业） | 点击进详情 |
| 同专业在售 | 按用户专业推荐教材 | 「换一批」换一页数据 |
| 20 元以内 | 低价专区，按价格升序 | 「换一批」 |
| 刚刚成交 | 近期卖出的书，制造"有人买"的信任感 | 「换一批」 |

> 「优先」书籍（卖家信用 ≥90）在列表中排在前面，书卡左侧有一条**金色细线**标识。

### 4.2 找书 `pages/search`

| 功能 | 说明 |
|---|---|
| 关键词搜索 | 支持书名、作者、出版社、ISBN |
| **拼音搜索** | 输入 `gdsx` 可搜到《高等数学》，`sjjg` 搜《数据结构》 |
| 搜索历史 | 本地保存，可清空 |
| 热门词汇 | 按在售书籍的课程热度聚合 |
| 排序 | 最新 / 热门 / 价格低 / 价格高 |
| 筛选 | 九成新以上、20 元内 |
| 空结果 | 显示热词推荐，引导换个词 |

### 4.3 书籍详情 `pages/detail`

信息密度最高的页面。

| 区块 | 内容 |
|---|---|
| 图片轮播 | 卖家实拍图，点击全屏预览、可双指缩放 |
| 基本信息 | 书名、作者、出版社、年份、价格、折扣 |
| 书况说明 | 品相、新旧、有无笔记、热度（同款在售数、近 30 天成交） |
| 卖家画像 | 头像、昵称、专业年级、信用分、成交数、好评率 |
| 卖家其他在售 | 横向滑动，方便凑单 |
| 相似推荐 | 协同过滤找的同类书 |
| 评价 | 有评价时显示「查看全部」入口 |

**底部操作栏**：收藏 / 还价 / 预约自提。已售出的书会变成「已售出 · 看看同款」，点击按课程名搜索同类书。

**特殊交互**：
- 点卖家头像/昵称 → 进入对方个人主页
- 「还价」→ 弹出输入框，发送砍价消息到聊天
- 「举报」→ 选择原因、填写说明，提交给管理员
- 「预约自提」→ 填写交接地点和备注，生成订单
- 下单成功后弹窗询问「要现在跟卖家约时间吗」，可直接跳聊天

### 4.4 发布闲置 `pages/publish`

| 步骤 | 操作 |
|---|---|
| 1. 上传图片 | 最多 6 张，客户端自动压缩后上传 |
| 2. 填写信息 | 书名（必填）、作者、出版社、出版年份、原价、售价 |
| 3. 选择书况 | 品相（1-5 星）、新旧程度、是否有笔记 |
| 4. AI 估价 | 点击「智能估价」，调用算法服务给出建议价与区间，可一键采纳 |
| 5. 提交 | 按信用分决定：≥90 直接上架 / 60-89 待审核 / <60 拒绝 |

### 4.5 订单 `pages/orders`

顶部两个 tab：**我买到的** / **我卖出的**。

每张订单卡片包含：订单号、状态标签、书籍封面与标题、价格、交接地点、**状态时间轴**、操作按钮。

| 状态 | 时间轴 | 可用操作 |
|---|---|---|
| 待确认 | 下单 ✓ → 确认 → 完成 | 买家：取消、申诉；卖家：确认 |
| 已确认 | 下单 ✓ → 确认 ✓ → 完成 | 买家：完成、申诉；卖家：申诉 |
| 已完成 | 全部打勾 | 买家：评价 / 查看评价 |
| 已取消 | 下单 ✓ → 已取消 | 申诉 |

**特色功能**：
- **超时倒计时**：待确认订单显示「卖家还有 23 小时确认，超时自动取消」，剩 2 小时内变红
- **评价**：星级 + 文字 + 最多 3 张图；已评价的可**修改**或**删除**
- **申诉**：订单有问题时提交，管理员介入

### 4.6 我的 `pages/me`

| 区域 | 内容 |
|---|---|
| 顶部 | 通知铃铛（未读角标）、设置 |
| 用户卡 | 头像、昵称、等级徽章、专业年级、个性签名 |
| **信用卡** | 信用分、等级进度条、三个特权筹码 |
| 数据条 | 在售 / 已售 / 收藏 / 被浏览 |
| 快捷入口 | 消息（未读角标）、信用规则、资料 |
| Tab 区 | 我的发布 / 我的收藏 / **浏览历史** |

**信用卡的视觉分级**：

| 等级 | 外观 |
|---|---|
| 黄金 95+ | 香槟金渐变 + 顶部金线 + 金色宝石 |
| 白银 85-94 | 冷灰蓝渐变 + 银色宝石 |
| 青铜 70-84 | 暖棕渐变 + 绿色宝石 |
| 待提升 <70 | 淡红警示 + 警示图标 |

三个特权筹码（免审核上架 / 首页优先 / 专属标识）会随分数点亮或置灰。

### 4.7 消息 `pages/chat`

会话列表 + 聊天窗口。

- 会话按最后消息时间排序，显示对方昵称、最后一条消息、未读数
- 聊天窗口支持**常用语**（这本书还在吗 / 书况怎么样 / 可以便宜点吗 / 今晚方便见面吗）
- 顶部显示关联书籍，可点击跳转详情

### 4.8 通知 `pages/notice`

系统推送的消息中心。

| 类型 | 示例 |
|---|---|
| 订单 | 「买家预约了你的书」 |
| 交易 | 「订单已完成，记得评价」 |
| 举报 | 「举报已处理：核实属实」 |
| 系统 | 「信用分已扣减：93 → 88」 |

点击查看详情，可跳转到关联订单/书籍；系统通知提供「去看我的资料」入口。支持「全部已读」。

### 4.9 信用分说明 `pages/credit`

### 4.10 全部评价 `pages/reviews`

- 顶部评分概况：平均分 + 5 档星级分布条
- 评价列表：头像、昵称、星级、内容、配图、日期

### 4.11 个人主页 `pages/user`

点任意用户的头像进入。

| 区域 | 内容 |

## 七、算法服务说明

地址 http://127.0.0.1:5001 ，与后端分离部署。

### 7.1 智能定价

**模型**：RandomForestRegressor

**特征（10 维）**：原价、品相等级、新旧程度、是否含笔记、出版年份、同款在售数、近 30 天成交数、分类、书龄、折扣率

**效果对比**：

| 模型 | MAE | RMSE | R² | MAE 占原价 |
|---|---|---|---|---|
| 基线（按原价打折） | 13.899 | 17.380 | 0.2653 | 24.06% |
| 线性回归 | 4.120 | 5.649 | 0.9224 | 7.13% |
| **随机森林（选用）** | **3.942** | **5.435** | **0.9281** | **6.83%** |

相比基线，定价误差从原价的 24.06% 降到 6.83%。

**输出**：建议价、价格区间（基于残差 10%/90% 分位）、置信度、特征贡献 Top5。

**边界处理**：输入会先做清洗（原价夹在 1~2000，品相 1~5），输出再夹一次（不低于 0.5 元、不高于原价），避免负数价格或天价。

### 7.2 推荐

三路召回 + 加权融合：

| 召回源 | 权重 | 说明 |
|---|---|---|
| ItemCF | α | 基于物品相似度 |
| 内容特征 | 1-α | 专业、课程、分类匹配 |
| 热度 | 固定 | 浏览/收藏加权 |

网格搜索得 **α=0.65** 时最优。

**效果**：

| 策略 | Recall@10 |
|---|---|
| 热门 | 0.0854 |
| ItemCF | 0.1357 |
| 内容 | 0.2915 |
| **融合** | **0.4322** |

相比纯热门策略提升 **406%**。

### 7.3 在线学习

- **定时重训**：每天 03:30 自动拉取最新数据重训
- **手动重训**：管理后台触发，调用 `POST /reload`
- 重训期间服务不中断，训练完成后原子替换模型

## 十二、设计说明

### 12.1 信用分体系

详见 [docs/信用分规则说明.md](docs/信用分规则说明.md)。

要点：

- 0-100 分，新用户 80 分起步
- **≥90 免审核直接上架 + 首页优先**
- 60-89 需审核
- <60 禁止发布
- 举报成立按原因分级扣分（诈骗 -20 到价格异常 -3）

### 12.2 定价策略

模型输出的是"市场公允价"，不是"卖家定价"。系统给出区间（建议价 ± 残差分位），卖方可自由调整。这样既辅助了不会定价的同学，又不剥夺定价权。

### 12.3 推荐策略

冷启动用内容特征（专业、课程匹配），有行为数据后逐步加大 ItemCF 权重。α=0.65 是离线网格搜索的结果。

### 12.4 交互细节

- 书卡去掉彩色标签堆叠，改为一行灰字元信息
- 高信用卖家的书用**左侧细金线**标识，不用文字标签
- 价格用「¥39.06 ~~¥128~~ 69%↓」三段式，折扣一眼可见
- 「我的」页去掉与 tabBar 重复的入口

## 十三、常见问题

**Q：小程序一片空白 / 图片不显示？**
A：检查是否勾选「不校验合法域名」，以及后端 8080 是否启动。图片是相对路径，需要后端返回完整地址。

**Q：新增的页面在小程序里打不开？**
A：开发者工具需要重新编译。菜单 → 工具 → 清缓存 → 全部清除，然后重新编译。

**Q：接口返回 401？**
A：Token 过期或未登录。所有接口 HTTP 都是 200，要看 `code` 字段。

**Q：算法服务连不上？**
A：确认 5001 端口在跑，访问 `http://127.0.0.1:5001/health`。重训要 2 秒左右，普通预测 1.5 秒超时。

**Q：开发者工具弹出「调试器加载错误」？**
A：这是工具自身的问题，不是项目报错。彻底退出后从**开始菜单**重新打开，或菜单 → 工具 → 调试 → 重新加载调试器。
